## Vision

### 10x Check
"AI가 더 좋은 메모를 쓴다"가 아니라 **사적 투자 운영체제**: 출처기반 리서치가 감시되는 트리거로, 트리거가 강제된 결정으로, 결정이 KOSPI 대비 채점된 트랙레코드로 전환되는 시스템. 12개월 후: 소유자의 모든 보유종목이 가드 커버리지 안에 있고, 채점된 알파 기록이 곧 제품(마켓플레이스 v0.2)의 신뢰 근거가 된다. 세션 유레카: 이 리포의 반환각(anti-hallucination) 규율 — 날짜 명시·출처 강제·반증 가능한 트리거 — 이 자가 채점의 원재료다. 생성만 붐비고 루프는 아무도 안 닫는 AI 리서치 도구 시장에서 유일한 차별점.

## Accepted Scope (added to this plan)

- kr-portfolio-guard 스킬: guard-sweep(트리거·가격·SMA/RSI·스테일·신규공시·미해결 플래그) → 한 화면 ACTION NEEDED(`~/stock-analysis-private/reports/`) → 플래그별 강세/약세 토론(LLM 레이어) → SELL/HOLD/ADD/REVIEW(+연기) 결정 강제 → decision-ledger.ndjson → KOSPI 대비 채점(1w/4w/12w, next-session close) → 메모 전수 백필 채점(unscoreable 마킹).
- E1: 결정 프롬프트에 비중 가이드 — **표시 전용(advisory-only), 강제 아님**. 산식(튜닝 가능한 기본값): 리스크예산(총자산의 0.5/1/1.5% ← 확신도 1–3) ÷ 무효화거리%(현재가→트리거가) = 포지션 상한. 예: 확신도 2, 무효화거리 8%, 총자산 1억 → 100만원 ÷ 8% ≈ 1,250만원 상한. 장부 필드 `confidence`·`qty_guide` (design doc Ledger Spec **v1.1**에 반영 완료). **스테이징:** 스키마 필드는 v1 첫날부터(백필 마이그레이션 방지), 사이징 프롬프트 UX는 가드 2회 실행 후 활성화.
- E2: 장부·백필·채점 스키마에 `channels[]` 태그(복수 허용) — 채널별 채점은 태그별 중복 계상(P&L 귀속 분할 아님). design doc v1.1에 반영 완료. 스키마 필드는 v1 첫날부터.
- E3: TODOS.md/CLAUDE.md에 우선순위 원칙 1문단(수익 루프 검증 전 발행 트랙 후순위).
- fetch-kr-chart.js `^KS11` 인덱스 패스스루 1줄.
- NO_MEMO degraded mode(솔루스), PARSE_GAP·DATA_GAP 규약, qty_change 수동입력 기반 포트폴리오 갱신.

**빌드 순서 & 총 노력:** ① Base 스크립트 + E1/E2 스키마 필드(day 1) → ② 첫 주간 가드 실행·토론·장부(week 1) → ③ E1 사이징 프롬프트 UX(가드 2회 실행 후) → ④ 채점+E2 어트리뷰션 리포트+백필(~week 8). 총 노력: CC 기준 ~1–2일(설계의 반나절–1일에서 E1·E2 반영 상향).
