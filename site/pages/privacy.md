# 개인정보처리방침

이 사이트는 회원가입이나 댓글 기능이 없으며, 방문자에게 이름·이메일 같은 개인정보를 직접 받지 않습니다.

## 동의 기반 방문 통계

첫 방문에 ‘통계 허용’과 ‘거절’을 같은 비중으로 안내합니다. 허용하기 전에는 분석 식별자를 만들거나 분석 이벤트를 전송하지 않습니다. 하단 ‘통계 설정’에서 언제든 변경할 수 있습니다. 거절·철회하면 전송을 중단하고 브라우저의 분석 식별자를 제거합니다. 이미 수집된 기록은 아래 보관 기간에 따라 삭제됩니다.

허용한 브라우저에 무작위 식별자를 최대 90일 보관합니다. 서버에는 HMAC으로 변환한 값만 저장합니다. 식별자는 이름이나 계정과 연결하지 않으며, 30분 이상 활동이 없으면 새 세션으로 구분합니다. 이전 세션 이력이 있는 브라우저를 재방문으로 봅니다. 저장소를 사용할 수 없는 환경은 해당 페이지 조회 단위로만 집계합니다. 허용 선택은 90일 후 다시 확인하며, 거절 선택은 설정을 바꿀 때까지 유지합니다.

수집 항목은 공개 페이지 경로, 세션 첫 진입 페이지, 외부 유입 도메인, utm_source·utm_medium·utm_campaign, 글의 최대 읽기 깊이, 활성 읽기 시간, 내부 글 링크 클릭입니다. UTM 값에는 이름·이메일 등 개인정보를 넣지 마세요. 허용된 짧은 캠페인 문자열만 받으며, 임의 쿼리 문자열과 전체 리퍼러 URL은 저장하지 않습니다. 탭이 보이고 최근 30초 안에 사용자 활동이 있을 때만 활성 읽기 시간을 계산합니다. 본문 90% 이상 도달하고 활성 읽기 30초 이상이면 완독으로 추정합니다.

분석 DB에는 IP 주소, 전체 User-Agent, 이름·이메일을 저장하지 않습니다. 상세 이벤트와 서버 식별자는 90일, 식별자가 없는 일별 집계는 365일 보관한 뒤 시간별 정리 작업에서 삭제합니다. 수집 목적은 글별 성과와 읽기 경험 개선이며, 제3자 광고 타기팅에 사용하지 않습니다. 통계 화면은 별도 관리자 비밀번호로 인증한 운영자만 접근합니다. 관리자 로그인은 보안 쿠키로 최대 8시간 유지하며 비밀번호를 분석 DB에 저장하지 않습니다. 동의한 브라우저에서 관측한 통계이므로 전체 방문자를 대표하지 않습니다.

## 쿠키와 광고

- 이 사이트는 Google AdSense 광고를 표시할 수 있습니다. Google을 포함한 제3자 광고 사업자는 쿠키를 사용해 방문자가 이 사이트와 다른 사이트를 방문한 기록을 바탕으로 광고를 게재할 수 있습니다.
- 맞춤 광고는 [Google 광고 설정](https://adssettings.google.com)에서 끌 수 있습니다. 제3자 사업자의 맞춤 광고 쿠키는 [www.aboutads.info](https://www.aboutads.info)에서 끌 수 있습니다.
- 유럽경제지역(EEA)·영국·스위스 방문자에게는 Google 인증 동의 관리 플랫폼(CMP)을 통해 동의를 받습니다.
- Google이 데이터를 사용하는 방식은 [Google 파트너 사이트 데이터 사용 방식](https://policies.google.com/technologies/partner-sites)에서 확인할 수 있습니다.

## 호스팅 로그

사이트는 Cloudflare Workers에서 제공됩니다. Cloudflare는 보안과 성능을 위해 IP 주소 등 접속 기록을 처리할 수 있습니다.
