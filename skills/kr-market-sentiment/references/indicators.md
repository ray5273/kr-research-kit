# 투심 바닥 지표 카탈로그 · 임계값 · 수집처

각 지표의 방향, 채점 밴드(−2 과열 … +2 강한 바닥), 가중치, 데이터 수집처. 임계값은
과거 한국 증시 저점 국면의 경험칙 기반 휴리스틱이며 통계적 확정이 아니다. 국면(구조적
저평가 vs 이익 사이클 저점)에 따라 조정 가능하다.

## A. 밸류에이션 (낮을수록 바닥)

### KOSPI 후행 PBR — weight 1.5 (수동)
- **논리**: 지수 PBR은 시장 전체의 청산가치 대비 가격. 역사적으로 KOSPI 저점은 PBR
  0.85~0.95배 구간에서 형성됐다(2008, 2020, 2022 등). 1배 이하 = 장부가 미만.
- **밴드**: ≤0.85 → +2 · 0.85~0.95 → +1 · 0.95~1.05 → 0 · 1.05~1.20 → −1 · >1.20 → −2
- **수집처**: KRX 정보데이터시스템 → 지수 → PBR/PER/배당수익률.

### KOSPI 12M 선행 PER — weight 1.0 (수동)
- **논리**: 이익 대비 밸류. 8~9배는 저평가 국면. 단, 이익 전망 자체가 하향되면 저PER이
  "이익 함정"일 수 있어 이익 추정 방향과 함께 본다.
- **밴드**: ≤8 → +2 · 8~9.5 → +1 · 9.5~11 → 0 · 11~13 → −1 · >13 → −2
- **수집처**: 연합인포맥스, 증권사 컨센서스 리포트.

## B. 변동성 / 공포 (높을수록 바닥)

### VKOSPI — weight 1.2 (수동)
- **논리**: KOSPI 옵션 내재변동성 지수(공포지수). 급등 = 투자자 공포 극대(capitulation),
  저점과 동행. 15 이하 장기 지속 = 안일/과열.
- **밴드**: <15 → −2 · 15~20 → −1 · 20~28 → 0 · 28~35 → +1 · ≥35 → +2
- **수집처**: KRX VKOSPI (일부 데이터 제공처는 `^KSVKOSPI` 등 심볼 미제공 → 수동 입력).

## C. 지수 기술적 (자동 계산)

### KOSPI 52주 고점 대비 낙폭 — weight 1.0
- **논리**: −20% 이상 = 약세장 진입, 과매도 배경. **필요조건이지 충분조건이 아니다**
  (더 깊어질 수 있음).
- **밴드**: ≤−25% → +2 · −25~−18 → +1 · −18~−10 → 0 · −10~−5 → −1 · >−5 → −2

### KOSPI RSI14 — weight 1.0
- **논리**: 일간 RSI 30 이하 = 과매도(바닥 신호), 70 근처 = 과열.
- **밴드**: <30 → +2 · 30~40 → +1 · 40~50 → 0 · 50~60 → −1 · ≥60 → −2

### KOSPI 200일선 이격도 — weight 0.8
- **논리**: 지수가 200일선 아래로 크게 이탈 = 추세 훼손·과매도. 위로 크게 이격 = 과열.
- **밴드**: ≤−12% → +2 · −12~−5 → +1 · −5~0 → 0 · 0~5 → −1 · >5 → −2

### KOSDAQ 낙폭 / RSI14 (보조지표) — weight 0.5 각각
- **논리**: 코스닥은 변동성이 커 더 깊은 낙폭을 바닥 기준으로 본다. 대형주 중심 KOSPI를
  보완하는 위험선호(risk appetite) 신호.
- **낙폭 밴드**: ≤−28% → +2 · −28~−20 → +1 · −20~−12 → 0 · −12~−6 → −1 · >−6 → −2
- **RSI 밴드**: KOSPI RSI와 동일.

## D. 수급 (범주형, 수동)

### 외국인 매매 추세 — weight 1.5, **확정 신호**
- **논리**: 외국인 순매도가 시장을 눌러온 뒤 **순매수 전환**은 바닥 '확정'에 가장 가까운
  신호. 대규모 지속 순매도/둔화는 capitulation 배경.
- **값 → 신호**: `net_buy_turn` +2 · `selling_slowing` +1 · `large_sustained_selling` +1 ·
  `neutral` 0 · `buying` −1 · `large_buying` −2
- **수집처**: KRX 외국인 매매동향(20일 누적 + 최근 5일 추세로 판단).

### 신용융자 잔고 추세 — weight 1.0
- **논리**: 잔고 급감(반대매매·강제 디레버리징)은 청산 국면 = 바닥 신호. 급증은 빚투
  레버리지 과열.
- **값 → 신호**: `plunging` +2 · `falling` +1 · `flat` 0 · `rising` −1 · `surging` −2
- **수집처**: 금융투자협회 신용공여 잔고.

### 투자자예탁금 추세 — weight 0 (맥락만)
- **논리**: **양면적**. 감소는 이탈·위축(바닥 배경)으로, 증가는 대기매수세(dry powder)로도
  읽힌다. 단독 신호로 쓰지 않고 맥락으로만 표시(합성 제외).
- **값 → 신호(표시용)**: `plunging`/`falling` +1 · `flat`/`rising` 0 · `surging` −1
- **수집처**: 금융투자협회 투자자예탁금.

## E. 시장 폭 (자동/수동)

### ADR 등락비율 20일 — weight 0.8 (수동)
- **논리**: 20일 상승/하락 종목 비율. 70~75% 이하 = 과매도(바닥), 120% 이상 = 과열.
- **밴드**: ≤70 → +2 · 70~80 → +1 · 80~95 → 0 · 95~115 → −1 · >115 → −2
- **수집처**: 네이버 증권 등락비율.

## F. 매크로 배경 (자동)

### 원/달러 환율 수준 — weight 0.5 (맥락)
- **논리**: 원화 약세 극단(환율 급등)은 외국인 이탈 스트레스 정점. 스트레스가 정점을 찍고
  되돌려질 때 지수 저점과 동행하는 경향. 직접적 바닥 지표라기보다 배경.
- **밴드**: <1280 → −2 · 1280~1330 → −1 · 1330~1400 → 0 · 1400~1450 → +1 · ≥1450 → +2

## 추가로 볼 만한 지표 (현재 스크립트 미포함)

수동으로 병합하거나 향후 확장 대상:
- 반대매매 금액 급증 (신용잔고와 함께 보면 청산 강도 확인)
- 신규 52주 신저가 종목 수 clustering
- 주식형 펀드 자금 유출입, ETF 순설정
- CDS 프리미엄·회사채 스프레드(신용 위험)
- 풋/콜 비율, 개인 순매수 capitulation
