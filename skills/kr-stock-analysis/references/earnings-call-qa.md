# 실적발표 컨퍼런스콜 Q&A

실적 발표 후 리뷰와 실적 이벤트를 반영하는 업데이트는 Q&A를 반드시 조사하고 본문에 `## 컨퍼런스콜 Q&A`를 포함한다. 발표자료의 준비 발언과 실제 질의응답을 구분한다. 콜이 없거나 공개 Q&A가 없으면 개최 여부·확인한 자료 범위를 짧게 밝히고 내용을 만들지 않는다. 내부 수집 실패 내역을 반복 노출하지 않는다.

- 회사 IR의 녹음·영상·공식 속기록을 우선한다. 없으면 공개 증권사 컨콜 정리, 전문매체의 Q&A 기사 순으로 찾는다. 게시물을 인용한 재게시물은 원 출처를 추적하고 재게시물끼리 일치한다고 독립 검증으로 세지 않는다. 모회사·자회사 및 다른 분기 콜을 섞지 않는다.
- 출처 등급: 회사 공식 녹음·속기록 > 증권사가 직접 배포한 PDF·리서치 페이지 > 전문매체 Q&A 기사 > 텔레그램·블로그 재게시본. 단축 링크(`yeouidonews.com/go`, `bit.ly` 등)와 텔레그램 미러(`tele.wiki`, `t.me`)만 남는 경우 원 게시 위치를 먼저 찾고, 못 찾으면 `## Sources` 라벨에 `재게시본` 또는 `단축 링크`를 명시한다. 재게시본만 근거인 답변은 `회사 답변 요약`으로 쓰되 분석의 단독 근거로 삼지 않는다(게이트 `source-reposts`).
- 콜 개최일·대상 분기·원 작성자·공개일·URL·자료 유형(공식 속기록/음성·영상/증권사 정리/기사)을 기록한다. 공식 녹음은 시각, 문서는 쪽수 또는 질문 제목으로 근거 위치를 남긴다. 증권사 요약문을 회사 발언 원문으로 표시하지 않는다.
- 중요한 질문과 답변은 질문 → 회사 답변 → 분석상 의미·다음 확인 조건 순서로 쓴다. 숫자의 기간·단위·조건·불확실성을 보존하고 비공개·미답변도 구분한다. 이익 차이·가이던스·수주/공급능력·투자·현금·주주 관련 답변을 우선하되 중요하지 않은 질문을 억지로 채우지 않는다.
- 정확한 표현이 중요한 부분은 확인된 원문을 짧게 인용하고 바로 출처를 붙인다. 제3자 전문·정리본 전체를 복제하지 않는다. 출처별 허용 인용·요약 범위를 지키고 나머지는 뜻을 보존해 요약한다. 직접 인용·번역·요약을 명확히 표시한다. 전문 재사용 권한이 확인되거나 사용자가 본문을 제공한 경우에는 허용 범위에서 원문을 보존할 수 있다.
- 자료 간 숫자·일정이 다르면 차이를 남기고 하나의 확정값으로 합치지 않는다. 회사 가이던스와 증권사 추정을 분리한다. 계약·생산능력·수요 전망을 확정 매출이나 실제 판매로 대체하지 않는다.
- 답변에서 새로 나온 목표·일정은 경영진 약속 및 다음 분기 점검 항목에 연결한다. 이번에 기록한 가설을 과거 성과로 소급 채점하지 않는다. 기존 원 기준일은 보존하고 반영일을 Update Log에 남긴다.
- 긴 Q&A는 좁은 표 대신 `### Q1. 질문 요지`, `### Q2. 질문 요지`처럼 1부터 연속 번호를 붙인다. 질문 번호는 편집 순서이며 실제 콜의 질문 순서라고 주장하지 않는다. 각 질문 아래 `**회사 답변 요약:**`(직접 인용이면 `**회사 답변:**`), `**분석:**` 또는 `**다음 확인:**` 문단을 사용한다. 사이트는 번호 배지·답변 배경·분석 구분선이 있는 한 열 카드로 표시한다. 전체 답변과 원문 링크를 보존하고 기본적으로 펼쳐 보여준다.
