# 실적 발표 전 예상치 복원

실적 리뷰의 시장 예상은 자료를 한 번 못 찾았다는 이유로 비워두지 않는다. analyst-report-discover → fetch → insight로 발표 전 리포트의 컨센서스 표와 원 제공자를 확인하고, 공개 데이터 제공자의 과거 시계열·발표 전 증권사 프리뷰·공개 텔레그램의 날짜가 있는 컨센서스 게시물을 조사한다. 목표주가 집계는 실적 예상이 아니다.

- 기준은 원칙적으로 발표 전날까지 공개된 예상이다. 확인된 마지막 관측점이 더 오래됐으면 실제 날짜를 표시하고 전날 값이라고 쓰지 않는다. 당일 예상은 발표보다 앞선 공개 시각이 입증될 때만 별도 처리한다.
- 현재 페이지에 과거 분기가 적혀 있다는 사실만으로 사전 예상으로 쓰지 않는다. 제공자의 날짜가 명시된 과거 시계열 및 발표직전(E) 항목, 또는 당시 게시된 문서/메시지의 원문과 대조한다. 조회 URL의 날짜 파라미터만 믿지 말고 응답 속 관측일·대상 분기를 확인한다.
- 과거 자료를 발표 후 복원할 수 있다. 데이터 기준일과 실제 확인일을 분리해 기록하고, 이후 추정치나 실제 결과를 사전 자료로 소급하지 않는다. 공개 자료의 기준일·분기·회계 기준·단위·집계 정의·URL·근거 위치를 남긴다. 표본 수가 미제공이면 숫자를 역산해 만들지 않는다.
- 텔레그램은 메시지 게시일·원 작성자·원 보고서/데이터 링크를 확인한다. 단순 재게시물을 독립 표본으로 세지 않는다. 발표 후 게시물의 ‘예상’ 숫자는 원시점 근거를 찾기 전 참고치로 분리한다.
- 매출·영업이익·순이익은 지표별로 대조한다. 특히 지배주주 순이익과 전체 당기순이익, 연결과 별도, 분기와 누적을 섞지 않는다. 같은 정의의 실제치가 있으면 비교 행을 따로 명확히 표시한다. 없는 항목을 EPS·주식 수 등으로 임의 역산하지 않는다.
- 집계 제공자·시점이 다른 숫자를 평균 내지 않는다. 최근의 검증 가능한 동일 제공자 자료를 기본값으로 정하고 다른 값은 날짜를 붙여 차이를 설명한다. 개별 증권사 추정은 시장 평균과 분리한다.
- 작성자 사전 예상이 없었다면 사후 작성하지 않는다. 재구성 시나리오가 필요하면 사후 시나리오로 명시해 사전 예상/서프라이즈 계산에서 제외한다.

**큰 비율은 금액부터:** 실제와 예상의 차이가 예상 대비 100% 이상이거나 일회성 요인(보상금·환입·처분이익 등)이 확인되면, 첫 문장은 금액 차이(예: `영업이익은 627.38억원 많았다`)로 시작하고 비율은 뒤에 붙인다. 같은 문장이나 바로 다음 문장에 예상치의 크기와 일회성 포함 여부를 쓴다. 굵은 문장에 100% 이상 비율만 두지 않는다(게이트 `ratio-headline`). 사이트 비교표는 100% 이상 비율에 `낮은 기저`를 자동 표시한다.

표에는 비교 가능한 숫자를 우선 배치하고 기준·출처·예외는 가까운 설명에 모은다. 작성자 사전 예상이 모든 지표에서 없으면 열과 ‘비교 불가’를 반복하는 대신 한 번만 안내한다. 원자료·개별 리포트·공개 게시물까지 확인한 뒤에도 남는 결측만 구체적으로 표시한다.
