## 프리뷰 배포 시도 — 2026-11-05

사용자의 후속 요청에 따라 npm run deploy:preview를 실행했다. 정적 빌드와 본문 검수 해시 일치 확인은 통과했지만 Wrangler 업로드는 실패했다.

- api.cloudflare.com 및 preview.kr-research-site.pages.dev의 DNS 조회 결과: ENOTFOUND.
- Wrangler 오류: 저장된 인증 토큰이 만료됐고 Cloudflare 인증 서버에 연결할 수 없어 갱신하지 못함. 저장된 인증 정보는 변경하지 않았다고 명시.
- 원격 프리뷰 주소는 갱신되지 않았다. 연결이 복구되면 같은 작업트리에서 npm run deploy:preview를 재실행하고 원격 본문을 확인해야 한다.
- 위 ‘원격 배포 미실행’ 기록은 최초 검증 시점의 상태이며, 이 후속 시도의 결과로 대체한다.

- 고정 주소를 캐시 우회 쿼리로 재조회해 HTTP 200을 확인했다.
