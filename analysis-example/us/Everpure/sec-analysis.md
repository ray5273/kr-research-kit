## 미공시 또는 별도 확인 필요

- SEC submissions/companyfacts API 및 직접 다운로드의 HTTP 403 때문에 issuer PDF로 대조했다. XBRL concept는 검증하지 않았고, 태그 미검증을 미공시와 혼동하지 않는다.
- 수치는 공시 본문 수동 추출이다. 원문 천 달러 값을 USD로 변환했고 주식 수·EPS 단위를 별도로 표시했다.
- parser `needs_review`는 짧은 섹션의 자동 추출 신뢰도 표지이며 공시 결손의 증거가 아니다. 전체 원문 검토 완료를 뜻하지 않는다.
- NAND 원가 비중·전가율·조달가격·royalty 단가·고객별 hyperscale 매출은 별도 공시되지 않았다.
- 최신 8-K는 확인 가능한 IR/SEC 공시 목록 기준이며 9월 투자자 행사에 별도 8-K가 있었다고 가정하지 않았다.
