# 하이브리드 A2 결과 — 상폐대가 교정은 무시가능

marcap 총수익 캐시(8.82%)에 상폐종목의 정확한 대가를 반영하면 숫자가 얼마나 바뀌는지 검증했다. **결론: 거의 안 바뀐다.**

## 절차
1. 표본 중 사라진 78종목을 OpenDART 공시 제목으로 유형분류(`delisted-consideration-classified.json`):
   - MERGER_OR_SUCCESSION 53 (합병·주식교환·지주전환 → 승계가치 ≈ 마지막 종가, carry OK)
   - **BANKRUPTCY_TOTAL_LOSS 20** (파산·정리매매 → 대가 ≈ 0)
   - GOING_PRIVATE_TENDER 1, UNKNOWN 4
2. 완전손실 20개 중 top300 캐시에 있는 **8개**(한진해운·에스모·제낙스·셀리버리·나노스·필룩스·파멥신·승화프리텍)를 터미널 종가 → ~0으로 강제하고 ablation 재실행.

## 결과: 변화 없음

| 계층 | 총수익(교정 전) | 하이브리드(완전손실 0 교정) |
|---|---:|---:|
| D. FULL | 8.82% | **8.82%** |
| B. RS+EPS | 12.31% | 12.31% |
| C. +레짐 | 11.80% | 11.80% |
| F. EPS만 | 12.65% | 12.65% |

소수점 둘째 자리까지 동일.

## 이유 (중요)
- **marcap 마지막 종가가 이미 붕괴값이다.** 완전손실 8개의 마지막 종가는 2년 고점 대비 **0~8%** (한진해운 0%, 셀리버리 0%, 나노스 0%, 에스모·제낙스 1%). 정리매매가 이미 ~92~100% 하락을 반영했으므로 carry-at-last-close가 이미 총손실을 근사한다. 마지막 1~8% → 0 잔차는 무시가능.
- **전략이 그 종목을 진작 팔았다.** 모멘텀·RS·EPS 선정은 폭락 중인 종목을 보유·매수하지 않는다. 60일 전 대비 이미 0~22%로 빠진 종목들.

## 함의: A2 불확실성 사실상 해소
- **8.82% 총수익 숫자는 이미 생존편향-정직하다** — 상폐 손실이 가격 경로에 내재. strict official 원장(정확한 합병 교환비율·상폐대가)을 만들어도 결과는 ~8~9%에서 **0.01%p 수준으로만** 움직일 것.
- 남은 strict official의 가치는 "감사 가능한 이중소스 증빙"이지 숫자 변화가 아니다.
- 따라서 대표 성과 **~8.8% 전체 / ~2.8% OOS**는 신뢰 가능한 최종값으로 취급 가능.
