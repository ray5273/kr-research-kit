# KOSPI·KOSDAQ 연도별 Top 300 재구성

이 디렉터리는 최신 구성종목을 과거 전체에 적용한 기존 결과와 분리된, 시점일치 Top 300 백테스트 산출물용이다.

> **대표 전략:** Minervini RS + DART EPS·매출 개선 + KOSPI 레짐 + 60일 18% 변동성 목표, 5거래일 리밸런싱·상위 10개. 가격 모멘텀 단독 산출물은 유니버스·가격 캐시 검증을 위한 보조 진단이며 모델 포트폴리오나 대표 성과가 아니다.

- 랭킹연도 `t`의 마지막 거래일 KOSPI·KOSDAQ 보통주 시가총액 Top 300만 `t+1`년 신호에 사용한다.
- ETF·ETN·리츠·스팩·우선주를 제외하고, 원시 Top 300 수·필터 후 수·기준일·순위·시총·원본 해시를 `universe-ledger.json`에 남긴다.
- 재구축 원장: [2015–2025 Top 300 보통주 원장](universe-ledger-2015-2025.json). 로컬 FinanceData/marcap 연말 스냅샷에서 다시 만들며, 메리츠금융지주는 보통주로 포함한다.
- 2016-07 시작에는 2015년말 스냅샷이 필요하다. 현재 저장소의 이전 XLSX는 2016–2025만 포함하므로, 숫자 결과를 게시하기 전에 2015 시트를 포함한 새 원본을 추출해야 한다.
- 가격 캐시는 연도별 합집합으로 준비하고 각 연도 보통주 유니버스의 90% 미만이면 실행을 중단한다. DART 결측은 가격 전략의 결측이 아니라 재무 신호 후보별 제외 사유로 기록한다.
- 기존 `trend-following-10y` 결과는 **최신 유니버스 생존자 편향 기준선**으로 그대로 보존한다.

## 기본 운용 동작

RS·EPS·매출·레짐 메인 전략의 기본 유니버스 정책은
[strategy-policy.json](strategy-policy.json)으로 고정한다. 매년 새 연말
스냅샷을 원장에 추가하면, 다음 해 첫 거래일에 기존 보유 전량을 청산하고
새 Top 300에서 상위 10개를 다시 고른다. 연중에는 기존처럼 5거래일마다
점수와 포트폴리오를 갱신한다.

생성 명령은 [KRX strategy-backtest skill](../../../../skills/kr-strategy-backtest/SKILL.md)의 “Annual Top-300 point-in-time universe” 절을 따른다.
