# KOSPI·KOSDAQ 연도별 Top 300 재구성

이 디렉터리는 최신 구성종목을 과거 전체에 적용한 기존 결과와 분리된, 시점일치 Top 300 백테스트 산출물용이다.

> **대표 전략:** Minervini RS + DART EPS·매출 개선 + KOSPI SMA200 레짐 단독, 5거래일 리밸런싱·상위 10개. **R1 채택(2026-07-18): 60일 18% 변동성 타깃은 수익 드래그로 제거**(복원은 `--vol-target 0.18`). 가격 모멘텀 단독 산출물은 유니버스·가격 캐시 검증을 위한 보조 진단이며 모델 포트폴리오나 대표 성과가 아니다.

> **⚠️ 대표 성과 재정박 (2026-07-18, official strict 확정 전 잠정):** 기존 헤드라인 **21.78% CAGR / −16.44% MDD는 대표 성과가 아니다.** raw-cache + price-jump 필터가 상폐·급락주를 제외해 생존편향·과적합으로 부풀려진 진단본이다. **생존편향-정직 + 배당 포함 총수익 기준 정직 성과는 CAGR 8.82% / MDD −36% (전체표본), OOS(2023–26) CAGR 2.83% / MDD −34%.** 헤드라인 −16% MDD는 in-sample 아티팩트다. 편향 분해: 21.78% = 정직 8.82% + 생존편향 ~4%p + 데이터선택 ~9%p + IS→OOS 과적합 ~6%p. 근거: `total-return-dividend-inclusive-*.md`, `overlay-ablation-sensitivity-*.md`, `strategy-redesign-*.md`.
>
> **R1 채택·엔진 반영 완료 (2026-07-18):** 60일 18% **변동성 타깃 제거**, KOSPI SMA200 ±3% **레짐 필터만 유지**(복원 `--vol-target 0.18`). ablation상 낙폭방어는 전부 레짐 몫(+21%p MDD, 공짜)이고 vol 타깃은 순수 수익 드래그(−3%p CAGR, MDD 개선 0)에 파라미터가 국소저점(과적합)이다. **R1 대표 성과(배당 포함 총수익): CAGR 11.80% / Sharpe 0.57 / MDD −36% / OOS 6.14%**, 동일가중 총수익 벤치마크 8.86% 대비 알파 ~3%p, 거래 −72%. 리포트: `annual-top300-R1-total-return-2017-01-02-through-2026-07-16.md`.
>
> **⚠️ 과신 금지:** R1 관측 Sharpe 0.57은 Deflated Sharpe 허들 0.79를 **통과하지 못한다**(~50개 구성 시험 대비 운으로 설명 가능). CAGR 90% 신뢰구간은 **−1.8%~29.3%**(하한 음수). 대표 성과로 쓰되 위험조정 알파가 통계적으로 확정된 것은 아니다.

- 랭킹연도 `t`의 마지막 거래일 KOSPI·KOSDAQ 보통주 시가총액 Top 300만 `t+1`년 신호에 사용한다.
- ETF·ETN·리츠·스팩·우선주를 제외하고, 원시 Top 300 수·필터 후 수·기준일·순위·시총·원본 해시를 `universe-ledger.json`에 남긴다.
- 재구축 원장: [2015–2025 Top 300 보통주 원장](universe-ledger-2015-2025.json). 로컬 FinanceData/marcap 연말 스냅샷에서 다시 만들며, 메리츠금융지주는 보통주로 포함한다.
- 2016-07 시작에는 2015년말 스냅샷이 필요하다. 현재 저장소의 이전 XLSX는 2016–2025만 포함하므로, 숫자 결과를 게시하기 전에 2015 시트를 포함한 새 원본을 추출해야 한다.
- 가격 캐시는 연도별 합집합으로 준비하고 각 연도 보통주 유니버스의 90% 미만이면 실행을 중단한다. DART 결측은 가격 전략의 결측이 아니라 재무 신호 후보별 제외 사유로 기록한다.
- 과거 상장폐지·합병 코드로 Yahoo 이력이 끊긴 2015–17 구간은 KRX `marcap` 원가격(분할만 추론 보정)으로 별도 검증한다. [초기 구간 커버리지 결과](price-coverage-marcap-legacy-2015-2017.json)는 2015년 95.7%, 2016년 95.0%, 2017년 93.3%로 모두 90% 게이트를 통과했다. 배당 조정 Yahoo 비교 성과와 혼합하지 않는다.
- 기존 `trend-following-10y` 결과는 **최신 유니버스 생존자 편향 기준선**으로 그대로 보존한다.
