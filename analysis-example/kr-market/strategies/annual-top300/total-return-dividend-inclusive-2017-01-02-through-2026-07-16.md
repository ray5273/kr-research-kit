# 배당 포함 총수익 정직 검증 (marcap + OpenDART 배당)

marcap split-only 캐시에 OpenDART 연간 현금배당(alotMatter, 604종목·4,123 배당-연도)을 재투자해 만든 **생존편향-정직 + 배당 포함** 총수익 캐시로 재검증. 여전히 strict official(이중소스 원장·정확한 상폐대가)은 아니다.

## 계층 ablation (전체표본, 2017-2026)

| 계층 | split-only | +배당(총수익) |
|---|---:|---:|
| A. RS만 | 8.24% | 8.17% |
| B. RS+EPS (오버레이無) | 11.38% | 12.31% |
| C. +레짐 | 11.19% | 11.80% |
| D. +vol (FULL, 현 설계) | 8.25% | **8.82%** |
| F. EPS만+레짐+overlay | 12.35% | 12.65% |

배당 효과가 전략 레벨에선 +0.6%p뿐(모멘텀·EPS성장주 저배당 + 레짐-off 현금 + 단기회전). 개별 삼성은 배당이 총수익 +29%p(10.9→14.1배).

## Walk-forward (IS 2017-22 / OOS 2023-26.7)

| 후보 | IS CAGR | IS MDD | OOS CAGR | OOS MDD |
|---|---:|---:|---:|---:|
| FULL (현 설계) | 9.82% | −16.21% | **2.83%** | **−34.33%** |
| R1 vol제거·레짐유지 | 12.55% | −21.10% | 6.14% | −32.09% |
| R3 순수EPS·레짐·vol제거 | 17.94% | −19.33% | 8.69% | −28.21% |
| R5 EPS+저변동 | 12.72% | −21.34% | 5.83% | −26.16% |

## 브래킷 정합 (배당 통제 완료)

| 캐시 | 상폐반영 | 배당 | CAGR |
|---|:--:|:--:|---:|
| marcap split-only | ✓ | ✗ | 8.25% |
| **marcap 총수익** | ✓ | ✓ | **8.82%** |
| Yahoo 조정 | ✗ | ✓ | 12.89% |
| 헤드라인 raw-cache | 필터제외 | ~✓ | 21.78% |

- **marcap-총수익(8.82%) vs Yahoo(12.89%) ≈ 4%p = 순수 생존편향** (배당 양쪽 통제 후 남은 차이 = 상폐 종목 포함 여부).
- 헤드라인 21.78% → 정직 총수익 8.82% (전체표본), **OOS 2.83%**. 갭 = 생존편향 ~4%p + 데이터선택/price-jump 필터 ~9%p + IS→OOS 과적합 ~6%p.

## 결론
1. 현 설계의 forward 기대치는 **한 자릿수 초반 CAGR + −34% MDD**. 헤드라인 −16% MDD·21.78% CAGR는 in-sample/생존편향/데이터선택 아티팩트.
2. **vol 타깃 제거(R1)** = OOS CAGR 2배(2.83→6.14%), 거래 −72%. 확정 개선.
3. 순수 EPS(R3)는 OOS 최고(8.69%)나 IS 과적합 경계 — official 캐시 재확인 후 판단.

## 방법론 한계
- 배당: OpenDART 연간(11011)만. 중간·분기배당 미포함(현 삼성 등 소폭 과소).
- 배당 ex-date는 사업연도 말일 근사.
- 상폐 종목은 마지막 종가 carry(정확한 정리매매/합병 대가 미반영) → 완전손실형은 과대평가 가능. 정확값은 A2 strict 원장 필요.
- 도구: `collect-dart-dividends.js`, `build-marcap-total-return-cache.js`.
