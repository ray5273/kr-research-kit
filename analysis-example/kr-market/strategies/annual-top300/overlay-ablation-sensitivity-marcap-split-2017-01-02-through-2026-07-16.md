# 오버레이 엣지 분해 + 파라미터 민감도 (Phase B)

- 캐시: marcap split-only (상폐 종목 포함, 배당 미조정 — **생존편향-정직 하한선**, carry). 공식 총수익 아님.
- 기간: 2017-01-02~2026-07-16; 유니버스는 전 config 동일(DART 커버 종목 고정); 비용·리밸런싱·상위10 동일.
- 목적: 헤드라인의 edge가 **종목선택(RS/EPS)인지 타이밍(레짐/vol)인지**, 그리고 오버레이 파라미터가 **과최적화**인지 노출.

## 3. 결론 (리뷰 확증)

1. **정직한 캐시에서 FULL 전략은 8.25% CAGR / Sharpe 0.52 / MDD −37%** — 헤드라인 21.78%도, Yahoo 12.89%도 아니다. 헤드라인은 데이터 선택(Yahoo 조정 + 가격점프 필터가 상폐·급락주 제외)이 만든 상향 편향.
2. **레짐 필터가 진짜 edge**: 거의 공짜(−0.18%p)로 MDD 58%→37%. 정확한 MA 윈도와 무관하게 낙폭방어는 견고.
3. **vol 타깃(18%/60일)은 순수 드래그**: −2.94%p CAGR, 낙폭 개선 0. 단조 민감도상 **끄는 게 최선**.
4. **선택된 오버레이 파라미터(MA200·band0.03·vol0.18·win60)는 국소 저점에 앉아 있다** — 생존편향 Yahoo 캐시에서 튜닝됐고 정직 캐시로 이식되지 않았음을 시사. **과최적화 신호.**
5. **EPS 슬리브 > RS 슬리브**: F(EPS만+레짐+overlay)=12.35%/Sharpe0.78이 D(50:50)=8.25%를 크게 상회. 약한 RS를 50:50으로 섞어 EPS를 희석 중. → Phase C 후보: EPS 비중↑·vol타깃 제거·레짐 유지.

주의: marcap carry 캐시라 절대 수준은 배당 미반영 하한선. 상대 분해·민감도 형태는 유효하나, 파라미터 국소저점은 일부 캐시 특이성일 수 있음 — A2 공식 총수익 캐시에서 재확인 권장.
