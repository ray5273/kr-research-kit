# 리밸런싱 체결 타이밍 검토 (TODO #2)

**결론:** 라이브 월간 리밸런싱이 백테스트 체결 규약보다 **1세션 늦다.** 장전(첫 거래일) 스케줄로 옮겨 정렬하는 것을 권장한다. 특히 **1월 연말 롤**에서 중요하다.

## 백테스트 권위 규약

`run-annual-top300-minervini-earnings-regime.js` (채택된 16.41% 전략, `--cadence 21`), 126행:

```js
for (i ...) { signal = allCalendar[i]; exec = allCalendar[i+1];
  annualRoll = exec.year !== signal.year;
  if (annualRoll) select(signal, exec, true);              // 전년 마지막 종가 -> 새해 첫 거래일 시가
  else if ((i - start + 1) % cadence === 0) select(signal, exec, false); }  // 21세션 그리드
```

- **체결:** 항상 signal 세션 **종가** → 다음 세션 **시가** (1세션 lag, 시가 체결).
- **인트라이어:** 백테스트 시작일 앵커의 **21세션 롤링 그리드**. 캘린더 월과 정렬되지 않는다.
- **연말 롤:** signal = 전년 **마지막 세션** 종가, exec = 새해 **첫 거래일** 시가. (연 1회 강제 재구성 · 새 Top-300 유니버스 발효 시점)

## 라이브 현재 동작

| 잡 | 스케줄 | 동작 | 백테스트 대비 |
|---|---|---|---|
| `krx-52w-high-rebalance` (build-live-krx-52w-monthly.py) | 매월 **1-3일 19:10** (장마감 후) | signal = D1 종가 → exec = **D2** 시가 | **1세션 늦음** ✗ |
| `krx-52w-high-portfolio` (일간 레짐) | 매일 17:25 (장마감 후) | 레짐 종가 평가 → 다음 세션 적용 | 일치 ✓ |

일간 레짐 잡은 규약대로다(종가 평가 → 다음 시가 적용). 문제는 **월간 리밸런싱 잡**뿐이다.

## 문제

- 백테스트 캘린더 정렬 리밸런싱 = **직전 세션 종가 → 첫 거래일 시가**.
- 라이브 = **첫 거래일(D1) 종가 → 둘째 거래일(D2) 시가** = **1세션 지연**.
- **1월 연말 롤에서 가장 크리티컬**: 백테스트는 전년말 종가로 첫 거래일 시가에 전량 재구성하는데 라이브는 D2 체결. 게다가 이 시점은 **TODO #1의 연간 Top-300 유니버스 교체**가 발동되는 바로 그날이라, 유니버스 정렬과 체결 정렬 오차가 겹친다.

## 권장안: 장전 첫거래일 스케줄

월간 리밸런싱 잡을 **첫 거래일 장전**(예: 08:30 KST)으로 옮기고, **직전 완료 세션 종가**를 신호로 써서 **첫 거래일 시가** 체결을 타깃한다.

1. **크론:** `매월 1-3일 19:10` → **매월 첫 거래일 장전 1회**(예: 08:20~08:40 KST). Hermes `jobs.json`에서 변경.
2. **빌더 로직:** 신호 세션을 "오늘(체결일) 직전 마지막 완료 세션"으로 **결정론적으로 고정**하고, execution = 오늘(첫 거래일). 현재는 `asof = 시세 마지막 날짜`, `execution = asof + 1영업일`이라, 장전 실행 시 Naver 일봉에 당일 장중 봉이 섞이면 `asof=D1`이 되어 여전히 D2로 밀린다. → **당일(체결일) 봉을 명시적으로 제외**해 `asof`가 항상 직전 완료 세션이 되게 해야 한다.
3. **발송 흐름:** 장전 텔레그램 신호 → 사용자가 시가 지정가/시장가 수동 주문(현행 "신호 자동·주문 수동" 유지).

### 한계 (정직)

- 이 변경은 **체결일 오프셋(D2→D1)만** 고친다. 라이브의 "캘린더 월간" 케이던스가 백테스트의 "21세션 롤링 그리드"의 근사라는 점은 그대로다(둘 다 ~월간, 정확한 리밸런싱 세션은 상이). 이건 라이브에서 불가피하며 수용 가능한 근사다.
- 강한 정당화는 **1월 연말 롤**(백테스트가 명확히 첫 거래일 시가 체결). 월중 리밸런싱은 롤링 그리드라 D1/D2가 사실상 위상 선택 문제 — 일관성을 위해 같이 장전 정렬 권장.

## 미결 (배포 · Hermes 박스에서)

- 빌더 패치(당일 봉 제외 → `asof` 결정론화)는 라이브 Naver 장전 응답 동작에 의존하므로, `HERMES_DRYRUN=1`로 첫 거래일 장전 드라이런 검증 후 배포한다.
- 크론 변경(19:10 days1-3 → 첫 거래일 장전)은 `jobs.json`에서.
